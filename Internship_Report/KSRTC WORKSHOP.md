# Bharat Stage 
* An old Indian emission standard equivalent to Euro 2.
* It is estimated based on **limits smoke, NOx, and particulate emissions**.
- **BS2 = older, simpler engine**
- **BS6 = newer, cleaner, sensor-heavy engine**

BS2 engines are much easier to work on mechanically.
Kerala mostly has BS2, Electric Vehicles are on BS6.

## Types of Engine used

|Feature|Ashok Leyland Hino / AL Engine|Tata Motors Cummins-based Engine|
|---|---|---|
|Origin|Hino technology (Japan) + Ashok Leyland adaptation|Cummins technology (USA) + Tata adaptation|
|Engine Layout|Mostly Inline 6|Inline 6|
|Power Range|160–180 HP|135–180 HP|
|Torque Delivery|Strong low-end torque|Smoother mid-range torque|
|Sound|Deep, rough “heavy” sound|Slightly smoother and less harsh|
|Fuel Pump|Mechanical inline pump|Mechanical rotary / inline (varies)|
|Maintenance|Simpler, rugged, easy repair|Slightly more precision required|
|Fuel Efficiency|Moderate|Usually better than AL in similar load|
|Overheating|More common if radiator weak|Better thermal management|
|Parts Availability|Very common in Kerala depots|Common, but depends on model|
|Driving Feel|Strong pulling power, hill-friendly|Smooth acceleration, better highway feel|
|Common Issues|Smoke, injector timing, clutch wear|Fuel pump wear, overheating, turbo issues|

## In General

**Ashok Leyland (Hino/AL):**

- Better for rough roads and overloaded routes
- Mechanics like it because it’s rugged
- Easier engine overhauls
- Feels more “raw” and powerful

**Tata Cummins:**

- Better mileage
- Smoother engine
- Better for long routes
- Slightly less forgiving if poorly maintained

# How does a Typical BS2 Engine Works ?

Air enters → turbo compresses it → diesel injected → combustion pushes piston → crankshaft rotates.

Main parts:

- **Engine block** → heart of engine
- **Piston** → moves up/down
- **Connecting rod** → transfers force
- **Crankshaft** → converts motion
- **Fuel injection pump** → controls diesel timing
- **Turbocharger** → increases power
- **Radiator** → cooling
- **Alternator** → charges battery
- **Air compressor** → builds air pressure for brakes

(Important in buses because brakes and doors often depend on air.)
